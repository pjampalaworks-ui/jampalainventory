Support — JampalaInventory

For invited shops in India and the United Kingdom

Contact the developer

Email: supportemail.ji@gmail.com

Write in English. Say which shop you are, and copy the phone ID from the sign-in screen if your question is about access.

Getting access

JampalaInventory opens only on a phone the developer has given access to. Open the app, tap Copy or Share under the phone ID on the sign-in screen, and send that ID to the developer. You will get back an activation code. Tap Paste, then Open Shop.

A code lasts for a set time. The app reminds you for 14 days before it ends and keeps every shop's data. When you get a new code, paste it in Settings → Enter New Code. A new or reset phone has a new ID and needs a new code.

Forgotten Owner PIN

Ask the developer for a reset code and paste it in Settings → Enter New Code. The PIN is removed and your shop data is untouched. Then set a new PIN in Settings → Owner & Staff.

Backups and a new phone

In Settings → Backup & Restore, tap Back Up Now to save one backup file with every shop. The file is encrypted so that only JampalaInventory can open it. On the new phone, get a new activation code, then use Restore from File.

Delete your data

Everything the app keeps is on your phone. To erase all of it (every shop's stock, bills and sales, your sign-in, any key you added, reminders and error notes), open Settings → Privacy & Security → Delete Account & Wipe Data and confirm. This cannot be undone.

The developer keeps only a list of the phone IDs it gave codes to, with the shop name you gave. To have your phone removed from that list, email the developer with your phone ID.
